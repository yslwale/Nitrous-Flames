# Nitrous Flames

**Multi-colored nitro flame particle effects for FiveM.**

A custom particle pack featuring multiple nitrous flame colors, designed for vehicle-focused FiveM servers, racing communities, and custom vehicle setups.

## Installation

1. Clone or download the repository.

```bash
git clone https://github.com/yslwale/Nitrous-Flames.git
```

2. Place the resource inside your FiveM server's streamed resources folder.

3. If you are using a nitrous script, you can choose which flame color to use. If your tuning system supports it, you can also add multiple colors and let players choose their preferred one.
